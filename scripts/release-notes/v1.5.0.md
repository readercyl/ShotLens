# v1.5.0

## 更新内容

- 改进截图选区识别：不再把图标、图片或不完整的文字行送入翻译，完整文字按视觉区域拆分语义块。
- OCR 优先使用快速识别；快速结果置信度不足时自动回退准确识别，并保留原图坐标与可选文字范围。
- 选区内所有文字统一发送到用户配置的模型翻译，常见多语义块最多使用两路并发，失败项按受控批次恢复。
- 译文按原文字块位置绘制，保持相关文字层级与字号；状态栏显示识别方式和翻译耗时，并随内容自适应宽度。
- 开发版与正式版使用独立的应用身份、设置和钥匙串，降低本地测试对正式版的影响。

## 兼容性

- Apple 芯片 Mac（M1 或后续型号）。
- macOS 14.0 或更高版本。
- 继续使用用户配置的兼容 OpenAI API；不内置公共 API、Key 或模型。
