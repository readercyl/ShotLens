# v1.4.4

## 更新内容

- 新增从截图、框选、OCR、内容规划、翻译到结果渲染的分阶段诊断日志，可在控制台直接复制诊断或打开日志目录。
- 错误提示会区分屏幕权限、OCR、网络、鉴权、限流和模型返回异常，并在可恢复时保留 OCR 结果直接重试翻译。
- 大段内容翻译支持分批进度与缺失项重试，个别语义块失败时保留已完成结果。
- API Key 改由 macOS 钥匙串保管，已有配置会在升级后自动迁移。
- 修复翻译结果工具条的状态文字显示不完整。

## 兼容性

- Apple 芯片 Mac（M1 或后续型号）。
- macOS 14.0 或更高版本。
- 继续使用用户配置的兼容 OpenAI API；不内置公共 API、Key 或模型。
