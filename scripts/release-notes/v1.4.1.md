# v1.4.1

- 修复大段文字翻译偶发只返回部分编号项导致整段失败的问题；缺项会按单项定向重试，超长语义块按自然句拆分后合并。
- 翻译结果在未收齐前不再显示半截内容；结果窗排版以完整显示为最高优先级，必要时允许继续缩小字号，避免最后一行被裁掉。
- 语义块只负责翻译上下文和阅读顺序，译文改为在整个结果窗内按流式区域重排；大段空白不再由原始 OCR 矩形传递到结果窗，多栏内容仍保持独立。
- 修复 pin → 取消 pin 后状态窗和操作窗失去跟随的问题；取消 pin 时会重新绑定所有 child windows，并清理已关闭的操作窗关系。
- 修复整窗重排时中文-only 内容仍留在底层截图造成的重复叠字；中文、数字和符号现在不调用 API，但会作为保留内容参与结果排版。
- 新增译文排版分类：短文本、标题和标签优先保留原位置，大段连续文本才启用结构化重排。
- 修复原位模式相邻 OCR 行高度被压缩为极小矩形，导致原文清除后译文只剩残影或底部一行的问题。
- 保持重新翻译从现有框选截图重新执行 OCR、语义分组、翻译和排版的完整路径。
