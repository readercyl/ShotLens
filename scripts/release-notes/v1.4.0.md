## 更新内容

- 修复小范围框选、单个英文单词和短词组的 OCR 识别稳定性；OCR 会自动增加上下文，并按原始框选范围过滤文字。
- OCR 改为英文片段级坐标；中英文混排时只翻译英文、只覆盖英文，中文保持原样。
- 将钉住图标移到结果浮框外侧，避免遮挡截图内容，并在屏幕边缘自动调整位置。
- 删除内置限免 API、公共 Key 和默认模型；现在必须配置用户自己的兼容 OpenAI API，模型名称可选。
- 保留用户已有的自定义 API 设置，新增更明确的未配置与 OCR 失败重试状态。

## 兼容性

- 支持 macOS 14.0 及以上版本。
- 本版本仍使用本地代码签名，不代表 Apple Developer ID 公证；首次打开可能需要在“隐私与安全性”中允许运行。
